# Smart Kisti Manager v25 – Final Ultimate Professional

Windows 11 desktop installment/DPS business management application.

## v25 PDF Reports
Use the **📄 PDF** button in the top toolbar or **Save PDF** inside report pages. A native Windows save dialog lets you choose the PDF filename and location.

Included reports: Reports & Export, Executive Center, Business Snapshot, Activity Log, Target & Closing, Cashbook, Analytics, Profit & Loss, Portfolio, Collection Forecast, Customer Ledger and Schedule.

## Build
`npm install` then `npm run build` or use GitHub Actions workflow `.github/workflows/build-windows.yml`.

The app stores data locally in the Windows user-data folder and retains the existing backup/restore functionality.
